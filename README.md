# Ahmed Vision — Android TV + Android Phone

مشروع مبدئي قابل للتعديل باستخدام Kotlin وJetpack Compose.

## جاهز الآن
- واجهة رئيسية عربية ملونة بأقسام القنوات والأفلام والمسلسلات وغيرها.
- شاشة إدخال بيانات Xtream أو كود تفعيل.
- دعم إطلاق التطبيق من مشغّل Android TV ومن الهاتف.
- مرجع بصري للتصميم المعتمد `design-reference.png`.

## لم يُنفّذ بعد
- ربط Xtream API، جلب التصنيفات والقنوات، تشغيل البث، EPG، البحث الفعلي، المفضلة الدائمة.
- خادم إدارة أكواد التفعيل، التحقق من صلاحية الاشتراك، حماية بيانات المستخدم.
- اختبار عملي على ريموت أجهزة التلفزيون والرسيفرات، وتجهيز APK موقّع.
- تحويل مرجع التصميم إلى خلفية وعناصر أصلية داخل التطبيق؛ الصورة محفوظة كمرجع وليست مستخدمة في الواجهة البرمجية بعد.

## تشغيل المشروع
1. افتح المجلد في Android Studio حديث مع JDK 17 وAndroid SDK 35.
2. اسمح لـ Gradle بتنزيل الاعتماديات.
3. شغّل app على هاتف Android أو محاكي Android TV.

ملاحظة: لا توجد قنوات أو اشتراكات أو بيانات سيرفر مضمنة. استخدم خدمات تملك حق الوصول إليها فقط. لا تدخل بيانات اشتراك حقيقية قبل تنفيذ الاتصال والتخزين الآمن.
